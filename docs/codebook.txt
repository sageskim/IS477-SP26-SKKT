#Data Dictionary
##Dataset: merged_cereal_gdp.csv

Location: data/processed/merged_cereal_gdp.csv

Description:
Merged dataset combining FAOSTAT cereal production data with World Bank GDP per capita data from 1961–2024.

Column Name	Type	Description
Country	string	Country name
Year	integer	Observation year
Cereal_Production_Value	float	Cereal production value in tonnes
Flag	string	FAOSTAT data quality flag
Flag Description	string	Explanation of FAOSTAT flag
GDP_per_capita_USD	float	GDP per capita in current USD

##Dataset: faostat_cereal_raw.csv

Location: data/raw/faostat_cereal_raw.csv

Source: FAOSTAT

Column Name	Type	Description
Area	string	Country or region
Year	integer	Year
Value	float	Production value
Unit	string	Measurement unit (tonnes)

##Dataset: worldbank_gdp_raw.csv

Location: data/raw/worldbank_gdp_raw.csv

Source: World Bank Open Data

Column Name	Type	Description
Country Name	string	Country name
Country Code	string	ISO-style country code
1960-2025	float	GDP per capita for each year
